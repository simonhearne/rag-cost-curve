Committed CSVs — the source of truth for every number in the talk.
One subdirectory per benchmark stage (`ws2/`, `ws3/`, ...), and one document per
topic beside them. Each CSV is written by exactly one notebook cell. If a
number is on a slide but not in this directory, the number is wrong by
definition.

Which `ws*` directory feeds which document: see the table in the repo
root's README.md, "Which `results/ws*/` directory belongs to which document".
